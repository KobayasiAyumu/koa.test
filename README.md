# My Smart Schedule 📅

Googleカレンダーのような直感的な操作性を実現した、ブラウザ完結型の週間スケジュール管理アプリです。
従来の「1時間ごとのマス目」ではなく、**分単位での自由なスケジュール調整**を可能にし、学生や社会人の細かいタスク管理をサポートします。

**👉 [デモサイトはこちら (Demo URL)](https://kobayasiayumu.github.io/koa.test/)**

## 💡 開発背景 (Background)

既存のシンプルなスケジュール帳アプリでは「1時間単位でしか入力できない」「開始時間がずらせない」という悩みがありました。
そこで、**「授業は90分」「バイトは15分刻み」**といった現実のスケジュールに柔軟に対応でき、かつスマホのアラーム設定のように直感的に操作できるツールを目指して開発しました。

## ✨ 特徴 (Features)

* **Free-Time Layout**: 1時間単位の枠にとらわれず、`9:15 - 10:45` のような細かい時間設定が可能です。
* **Smart UI**: グリッドをクリックするだけで入力画面が起動。直感的なモーダルウィンドウを採用しています。
* **Easy Time Control**: 時間入力欄に「▲▼」ボタンを設置し、クリックだけで15分刻みの調整ができるようにしました（スマホ操作を意識）。
* **Color Coding**: 「勉強(青)」「重要(赤)」「バイト(橙)」など、色分け機能で視認性を高めています。
* **Image Export**: 作成したスケジュールをワンクリックで画像(PNG)として保存・共有できます。

## 🛠 使用技術 (Tech Stack)

* **Frontend**: HTML5, CSS3, JavaScript (Vanilla JS)
* **Libraries**: [html2canvas](https://html2canvas.hertzen.com/) (画像保存機能に使用)
* **Storage**: LocalStorage (ブラウザへのデータ保存)

## 🚀 技術的なこだわり (Technical Highlights)

### 1. 時間の座標変換ロジック (Time-to-Pixel)
予定の「開始時間」と「終了時間」から、画面上の正確な位置（top）と高さ（height）を動的に計算して描画しています。
これにより、アナログな表計算では不可能な**「時間の重なり」や「半端な時間」**を正確に可視化しました。

```javascript
// 時間(09:30) を ピクセル(px) に変換する計算式
function timeToPx(timeStr) {
    const [h, m] = timeStr.split(':').map(Number);
    // (時 * 60px) + (分 / 60 * 60px)
    return ((h - START_HOUR) * HOUR_HEIGHT) + ((m / 60) * HOUR_HEIGHT);
}
2. UI/UXの徹底的な改善
当初は時刻が見切れる問題がありましたが、CSSの flexbox を活用してレスポンシブな入力フォームを実装しました。 また、時間軸とグリッド線の高さが1pxでもズレないよう、box-sizing とスペーサー要素を用いてピクセルパーフェクトなレイアウトを実現しています。

3. ステート管理
予定データはJSON形式で管理し、追加・編集・削除のたびに即座に再描画とローカルストレージへの保存を行っています。これにより、ページを閉じてもデータが消えません。

📖 使い方 (How to use)
カレンダーの空いている場所をクリックすると、新規作成画面が開きます。

タイトル、曜日、時間を入力し、色を選んで「保存」します。

作成されたカードをクリックすると、再編集や削除が可能です。

「📷 画像保存」ボタンで、スケジュール表を画像としてダウンロードできます。
